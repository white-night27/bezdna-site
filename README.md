# Бар «Бездна» на Рижском

Сайт собран на основе предоставленного `index (3).html` и использует исходный
логотип `Resurs-1-11 (1).svg`.

## Где менять содержимое

- `app/content.ts` — контакты, внешние ссылки, навигация, меню и особенности.
- `app/page.tsx` — текстовые блоки и порядок разделов страницы.
- `app/globals.css` — исходные стили референса, адаптивность и размеры логотипа.
- `public/logo.svg` — основной логотип; файл можно заменить без правок кода.
- `public/favicon.svg` — компактная иконка вкладки, сделанная из знака логотипа.
- `public/og.png` — карточка сайта для Telegram и других социальных сетей.

Оригинальные файлы сохранены без изменений в папке `reference/` для сверки.

## Что учтено

- Адаптивная навигация и мобильная кнопка бронирования.
- Семантические разделы, русская локаль, клавиатурный фокус и режим без анимации.
- SEO-метаданные, Schema.org, Open Graph и фирменный фавикон.
- Все внешние ссылки, открывающиеся в новой вкладке, используют
  `rel="noopener noreferrer"`.
- Нет сторонних виджетов, трекеров и внешних исполняемых скриптов.

## Проверка

```bash
pnpm test
```

Проверка собирает сайт и подтверждает наличие исходного логотипа, меню,
контактов, безопасных ссылок и редактируемого файла данных.

## Публикация на Vercel

Проект подготовлен как Next.js-сайт для Vercel.

```bash
npx pnpm install
npx pnpm dev
npx pnpm build
```

Для публикации отправьте проект в GitHub и импортируйте репозиторий в Vercel.
Vercel возьмет настройки из `vercel.json`: `pnpm install` и `pnpm build`.
